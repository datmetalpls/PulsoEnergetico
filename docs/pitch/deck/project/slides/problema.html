EL PROBLEMA

La boleta llega cuando ya es tarde

En una sede comunitaria nadie mira la energía hasta fin de mes. Para entonces ya no se puede cambiar nada.

Luces olvidadas

La sala de reuniones queda encendida y vacía después de la actividad.

Dato tardío

El consumo se conoce con la boleta, semanas después.

Sin límite visible

No hay un presupuesto a la vista que avise antes de pasarse.
